# موقع مؤسسة همّة للسياحة والسفر والحج والعمرة

موقع ثابت (HTML / CSS / JavaScript) بدون مكتبات.

## التشغيل
افتح `index.html` بالمتصفح (مع إنترنت لتظهر الصور الحقيقية)، أو ارفع المجلد على أي استضافة (Netlify Drop، cPanel…).

## الصفحات
| الملف | الصفحة |
|---|---|
| index.html | الرئيسية |
| about.html | من نحن + رئيس الحملة |
| services.html | الخدمات (8 خدمات) |
| packages.html | الرحلات: عمرة / سياحة / علاجية + نافذة تفاصيل |
| medical.html | السياحة العلاجية |
| ziyarat.html | المزارات في مكة والمدينة |
| guide.html | دليل المعتمر + الأسئلة الشائعة |
| booking.html | حجز من 4 خطوات يُرسل على واتساب |
| contact.html | التواصل + خريطة |

## الصور
صور حقيقية من Unsplash (رخصة Unsplash: مجانية للاستخدام التجاري) تُحمّل من الإنترنت.
إذا ما فتحت الصورة بيظهر بدالها رسم SVG تلقائياً.
لتبديل أي صورة: عدّل `PHOTO` في `js/data.js` (معرّف الصورة من رابط images.unsplash.com).

## التعديل
كل المعلومات (الأرقام، العنوان، الخدمات، الرحلات، الأسعار، الأسئلة) بملف `js/data.js`.
